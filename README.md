# ExamFlow - Online Exam and Result Management System

## About Project
ExamFlow is an Online Examination and Result Management System developed using React.

## Features
- Student Login
- Admin Login
- 20 Online Exams
- 400 Questions
- Online Examination with Timer
- Automatic Result Calculation
- Student Dashboard
- Admin Dashboard
- Student Result Management

## Technologies Used
- HTML
- CSS
- JavaScript
- React
- Vite
- Local Storage
